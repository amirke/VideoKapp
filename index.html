Time zone and synchronization
GPS timestamps in FIT and timestamped GPX/KML already identify absolute instants. GPS time zone displays them in your clock. Video time zone also interprets local video timestamps when selected above. The original timeline stays unchanged.
Offsets use the first video/GPS date, including daylight saving. Before loading a date, current offsets are shown. Favorites appear first.
Time zones change display only. Clock corrections shift the video or GPS timeline independently. Use 0 for an accurate source clock; the start fields update automatically.
Correction is added to the video's recording time. Example: camera clock is one hour behind GPS → +3600 seconds. Display time zone only changes labels.

Buttons — what to use and when
  1. Choose original video: select the full-quality source.
  2. CONVERT: create the small video for AI, plus prompt and identity manifest. It does not upload.
  3. Copy prompt: paste into Gemini with the small video. Request a downloadable JSON file; import it unchanged.
  4. Import Gemini JSON: validate and display its proposed cuts.
  5. Choose timeline / GPS: optional, for synchronized map preview.
  6. Time settings in Ride Player: configure how recording timestamps are interpreted.
  7. Preview: play one proposed interval. Preview source selects original or small copy.
  8. Save clips + GPS JSON: optional export of proposed cuts and matched GPS samples.
  9. Export reviewed clips: create the final video from checked intervals in the original.
  10. Refresh map / Fit route: reload map tiles or show the whole route.
Use the GEMINI tab for automatic API analysis, or submit the small copy manually and import the returned JSON below. Keep the same original selected.
