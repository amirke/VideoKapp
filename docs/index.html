Install or open VideoKapp

Windows x64 · Version 3.8.4 · Runs locally on your computer.

Download & install

Install once on each computer. The package includes the required video tools.

Download ZIP — Windows x64

Version 3.8.4 · Release details & checksum

  1. Download the ZIP, then right-click it and select Extract All.
  2. Open the extracted folder and double-click Install.cmd.
  3. Wait for Installed successfully. The installer adds desktop and Start menu shortcuts and enables the website launch button.
  4. Use Open VideoKapp on this page.

Installed for your Windows user. No administrator rights required. On managed computers, your organization may restrict scripts or unsigned applications.

Open installed application

Opens VideoKapp, or brings its existing window to the front.

Open VideoKapp

Install once on each computer to enable this button.

Nothing opened?
  1. Accept your browser's request to open the external application, if shown.
  2. If Windows cannot find an app for this link, follow the Download & install instructions.
  3. You can also open VideoKapp using its desktop shortcut.

This page cannot verify whether the desktop app opened. It does not automatically download or reinstall anything.

Optional AI tools, updates and portable use

Ollama and its models are separate, optional downloads. Gemini needs your API key. Online maps and cloud services require internet.

For an update, close VideoKapp and repeat the download and installation steps. The installer selects the new version for shortcuts and website links; older version folders and your settings remain intact.

For portable use, extract the ZIP and run ChronoMerge.exe directly. Keep all extracted files together. Website launching requires running Install.cmd.

Installation location: %LOCALAPPDATA%\Programs\VideoKapp\3.8.4. User data remains in the existing ChronoMerge profile.
