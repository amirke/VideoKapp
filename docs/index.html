More

Portable use: extract the ZIP and run ChronoMerge.exe. Website launch requires installation.

Ollama and models are optional downloads. Gemini requires an API key.

In the app: Tests → Check & download update → Install & restart. Only changed components download. Settings and the previous version are kept.
